ฉันต้องการพัฒนาภาษาโปรแกรมมิ่งเป็นของตัวเองซึ่งมีชื่อว่า mvs
โดยที่ภาษานี้เขียนด้วย C เพื่อเป็น host complier ในช่วงแรง (ช่วงกำลังพัฒนา)
โดยหลักการ compile คือแปลง code เป็น assembly ที่สามารถทำงานได้ใน X86_64 (Windows)
มีการแยกไฟล์ชัดเจน + คอมเม้นใน code compiler เป็นภาษาไทย (แค่ comment นะส่วน output ให้เป็น eng ปกติ) แบบละเอียดว่าทำงานอะไรบลาๆ
และก็ codegen ที่เอาไว้ gen assembly ทำให้มันรองรับสถาปัตยกกรรมอื่นในอนาคตด้วย

features: การประกาศตัวแปร, ฟังก์ชั้น, แสดงผล, การนำเข้าไฟล์อื่นๆ, การดำเนินการทางคณิตศาสตร์ และอื่นๆตามตัวอย่างที่ส่งให้

// The MVS Language


// นี่คือการคอมเม้นแบบหนึ่งบันทัด


/*
 * นี่คือการคอมเม้นแบบหลายบันทัด
 */


/* Data Type ที่รองรับ:
 * i8, i16, i32, i64, i128, isize, u8, u16, u32, u64, u128, usize, bool(true/false), void, str, char, f32, f64, struct, pointer
 * รองรับการทำงานกับ pointer เหมือนๆ C
 */


/* เป๋าหมายของภาษาโปรแกรม mvs นี้ออกแบบให้เป็น Low Level Language ที่อยู่ในระดับเดียวกันกับ C
 * แต่เขียนง่ายกว่า C ด้วย syntax ที่เข้าใจง่าย ภาษานี้เน้นไปที่การจัดการ memory ด้วยตัวเองเหมือน C
 */


/* ตัวดำเนินการทางคณิตศาสตร์
 * +     การบวกเลข
 * -     การลบเลข
 * *     การคูณเลข
 * /     การหารเลข
 * %     การมอดหาค่าเศษจากการหาร
 * ^     การยกกำลัง
 * และรองรับการทำงานตามลำดับความสำคัญของตัวดำเนินการ รวมถึงการใช้ `()` ในการคำนวนเช่น (10 - 5) * 3
 */


/* ตัวดำเนินการเปรียบเทียบท
 * ==     เปรียบเทียบความเท่ากัน
 * !=     เปรียบเทียบความไม่เท่ากัน
 * <      น้อยกว่า
 * >      มากกว่า
 * <=     น้อยกว่าหรือเท่ากับ
 * >=     มากกว่าหรือเท่ากับ
 */


/* การประกาศตัวแปร
 * โดยการประกาศตัวแปรจะรองรับทั้งการประกาศภายใน block scope และนอก block scope (global)
 * และรองรับการประกาศแบบ pointer เหมือนกับ C
 * ส่วนลำดับการเข้าถึงตัวแปรนั้นจะขึ้นอยู่กับ scope คล้ายๆภาษา C
 * ตัวอย่างการประกาศตัวแปร
 * let name: type = value;
 * const cname: type = value; สำหรับค่าคงที่
 */
let msg: str = "";
const cmsg: str = "";


/* การประกาศตัวแปร struct
 * โดยการประกาศตัวแปรจะรองรับทั้งการประกาศภายใน block scope และนอก block scope (global)
 * สามารถเข้าถึงค่าภายใน struct ได้ด้วย key ที่กำหนดไว้เช่น let user: User; user.age; และรองรับการเข้า
 * ถึงแบบ nested struct และรองรับการประกาศแบบ pointer เหมือนกับ C
 * ส่วนลำดับการเข้าถึงตัวแปรนั้นจะขึ้นอยู่กับ scope คล้ายๆภาษา C
 * ตัวอย่างการประกาศตัวแปร
 */
struct User {
    username: str;
    age: u8;
}


/* Syntax พื้นฐานและการควบคุมการทำงาน (Control Flow)
 * let            - ประกาศตัวแปรแบบเปลี่ยนค่าได้ (mutable variable)
 * const          - ประกาศตัวแปรแบบค่าคงที่ (immutable constant)
 * struct         - ประกาศโครงสร้างข้อมูล (structure)
 * func           - ประกาศฟังก์ชัน (function definition)
 * ->             - กำหนดว่าฟังก์ชั่นคืนค่าอะไร
 * return         - คืนค่าผลลัพธ์และออกจากฟังก์ชัน
 * if-elseif-else - เงื่อนไขแบบเลือกทำงานตามกรณีต่าง ๆ
 * switch-case    - เงื่อนไขแบบเลือกทำงานตามค่า case ต่าง ๆ
 * for            - ลูปสำหรับทำซ้ำตามจำนวนครั้งที่กำหนด
 * while          - ลูปทำซ้ำตราบใดที่เงื่อนไขเป็นจริง
 * do-while       - ลูปทำซ้ำอย่างน้อยหนึ่งครั้ง แล้วตรวจสอบเงื่อนไข
 * break          - ออกจากลูปหรือ switch ทันที
 * continue       - ข้ามรอบลูปปัจจุบันไปยังรอบถัดไป
 * import from    - นำเข้าโมดูลหรือไฟล์โค้ดอื่น ๆ
 * //             - คอมเมนต์แบบบรรทัดเดียว
 * /* ... */      - คอมเมนต์แบบหลายบรรทัด
 */


/* Standard Library (std)
 * io          - สำหรับงาน Input/Output เช่น อ่านเขียนไฟล์, รับข้อมูลจากผู้ใช้, หรือเขียนข้อมูลออกไปยังจอภาพ
 * fs          - จัดการไฟล์และโฟลเดอร์ เช่น สร้างไฟล์, ลบไฟล์, อ่านไฟล์
 * net         - สำหรับงานเครือข่าย เช่น TCP/UDP sockets
 */
import { io, fs, net } from "std"; // ตัวอย่างการนำเข้า Standard Library
import { my_func } from "./lib"; // (lib.mvs) ตัวอย่างการนำเข้า Lib ที่เขียนขึ้นมาเอง
// (เดี๋ยวค่อยมาคิดอีกรอบว่าจะเอาไง)

 * ตัวอย่างโปรแกรม

const APP_NAME: str = "MVS APP";

func myUser(username: str, age: u8 = 5) -> User {
    return User {
        username: username,
        age: age
    };
}

// จุดเริ่มต้นของโปรแกรม (Entry Point)
func main() -> i8 {

    let msg: str = "Welcome to" + " " + APP_NAME;

    let y: u8 = 10;
    const result: u8 = x + y;

    let ch: char = 'Y';

    let user: User = User { username: "alice", age: 25 };
    let user2: User = myUser("bob");
    let user3: User;
    user3.username = "jodo";
    user3.age = 21;

    // let ptr: *u8 = malloc(100); // Allocate 100 bytes
    // free(ptr); // Free allocated memory

    let ptr: *u8 = &y;
    let val: u8 = *ptr;

    let age: u8 = user.age; // Access struct field

    let even_counter: u8 = 0;
    for (let: u8 i = 0; i <= 100; i++) {
        if (i % 2 == 0) {
            even_counter++;
        }
    }

    return 0;
}
